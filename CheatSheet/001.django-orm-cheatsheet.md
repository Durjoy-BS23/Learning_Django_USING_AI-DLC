# Django ORM Cheatsheet

## Setup (Models & Migrations)

### Define Model
```python
from django.db import models

class Post(models.Model):
    post_title = models.CharField(max_length=60)
    post_content = models.TextField()
    published_date = models.DateTimeField(auto_now=True)
```

### Field Types
```python
# CharField - requires max_length
title = models.CharField(max_length=100)

# TextField - no max_length
content = models.TextField()

# DateTimeField
created_at = models.DateTimeField(auto_now_add=True)  # Set once on creation
updated_at = models.DateTimeField(auto_now=True)      # Updates on every save

# IntegerField
count = models.IntegerField()

# BooleanField
is_active = models.BooleanField(default=False)

# DateField
birth_date = models.DateField()
```

### Run Migrations
```bash
python manage.py makemigrations  # Create migration files
python manage.py migrate         # Apply migrations
python manage.py showmigrations  # Check status
python manage.py sqlmigrate app 0001  # View SQL
```

### Django Shell
```bash
python manage.py shell  # Start
exit()  # Exit
```

## Create Data

### Method 1: save()
```python
from post.models import Post

post = Post(
    post_title="Title",
    post_content="Content"
)
post.save()
```

### Method 2: create()
```python
from post.models import Post

post = Post.objects.create(
    post_title="Title",
    post_content="Content"
)
```

### Bulk Create
```python
posts = [Post(post_title=f"Post {i}", post_content=f"Content {i}") for i in range(100)]
Post.objects.bulk_create(posts)
```

### Access Created Object
```python
print(post.id)
print(post.post_title)

```

## Read Data

### Retrieve All
```python
from post.models import Post

all_posts = Post.objects.all()
```

### Retrieve Single Object
```python
# Using get() - raises exception if not found/unique
post = Post.objects.get(id=1)

# Using get_object_or_404 - raises 404 if not found
from django.shortcuts import get_object_or_404
post = get_object_or_404(Post, id=1)

# Using first() - returns None if empty
post = Post.objects.all().first()
```

### Filter Data
```python
# Basic filter
posts = Post.objects.filter(post_title__icontains="django")

# Multiple conditions (AND)
posts = Post.objects.filter(
    post_title__icontains="django",
    id__gt=5
)
```

### Exclude Data
```python
posts = Post.objects.exclude(post_title__icontains="test")
```

### Order Data
```python
# Ascending
posts = Post.objects.all().order_by('post_title')

# Descending (prefix with -)
posts = Post.objects.all().order_by('-published_date')

# Multiple fields
posts = Post.objects.all().order_by('-published_date', 'post_title')

# Reverse current order
posts = Post.objects.all().order_by('published_date').reverse()
```

### Count Data
```python
# Efficient - uses SQL COUNT
count = Post.objects.all().count()

# Or on filtered
count = Post.objects.filter(post_title__icontains="django").count()
```

### Get Specific Fields
```python
# Returns dictionaries
posts = Post.objects.values('post_title', 'published_date')

# Returns list of single values
titles = Post.objects.values_list('post_title', flat=True)
```

## Field Lookups

### Syntax
```python
field__lookup=value  # Double underscore separates field from lookup
```

### Comparison Lookups
```python
# Greater than
Post.objects.filter(id__gt=5)

# Greater than or equal
Post.objects.filter(id__gte=5)

# Less than
Post.objects.filter(id__lt=5)

# Less than or equal
Post.objects.filter(id__lte=5)
```

### Text Lookups
```python
# Case-sensitive exact
Post.objects.filter(post_title__exact="Django")

# Case-insensitive exact
Post.objects.filter(post_title__iexact="django")

# Case-sensitive contains
Post.objects.filter(post_title__contains="Django")

# Case-insensitive contains
Post.objects.filter(post_title__icontains="django")

# Case-sensitive starts with
Post.objects.filter(post_title__startswith="Django")

# Case-insensitive starts with
Post.objects.filter(post_title__istartswith="django")

# Case-insensitive ends with
Post.objects.filter(post_title__iendswith="tutorial")
```

### List Lookup
```python
Post.objects.filter(id__in=[1, 3, 5, 7])
Post.objects.filter(post_title__in=["Django", "Python", "Web"])
```

### Date Lookups
```python
from datetime import datetime

# Range
start = datetime(2024, 1, 1)
end = datetime(2024, 12, 31)
Post.objects.filter(published_date__range=(start, end))

# Year
Post.objects.filter(published_date__year=2024)

# Month
Post.objects.filter(published_date__month=1)

# Day
Post.objects.filter(published_date__day=15)

# NULL check
Post.objects.filter(post_title__isnull=True)
Post.objects.filter(post_title__isnull=False)
```

### Regular Expression
```python
# Case-sensitive
Post.objects.filter(post_title__regex=r'^Django \d+')

# Case-insensitive
Post.objects.filter(post_title__iregex=r'^django \d+')
```

### Case-Insensitive Prefix Reference
| Lookup | Case-Sensitive | Case-Insensitive |
|--------|----------------|------------------|
| exact | `exact` | `iexact` |
| contains | `contains` | `icontains` |
| startswith | `startswith` | `istartswith` |
| endswith | `endswith` | `iendswith` |

## Advanced Querying

### Q Objects (AND, OR, NOT)
```python
from django.db.models import Q

# AND
Post.objects.filter(
    Q(post_title__icontains="django") & Q(id__gt=5)
)

# OR
Post.objects.filter(
    Q(post_title__icontains="django") | Q(post_title__icontains="python")
)

# NOT
Post.objects.filter(~Q(post_title__icontains="test"))

# Complex combination
Post.objects.filter(
    (Q(post_title__icontains="django") & Q(id__gt=5)) | Q(post_title__icontains="python")
)
```

### Limit Results (Slicing)
```python
# First 5 posts
posts = Post.objects.all()[:5]

# Posts from index 5 to 10
posts = Post.objects.all()[5:10]

# Every other post
posts = Post.objects.all()[::2]

# Most recent 10
posts = Post.objects.all().order_by('-published_date')[:10]
```

**Note:** No negative indexing on QuerySets (use `.last()` instead)

## Update Data

### Update Single Row
```python
from post.models import Post

post = Post.objects.get(id=1)
post.post_title = "Updated Title"
post.save()
```

### Update Multiple Rows
```python
# Update all matching rows
count = Post.objects.filter(
    post_title__icontains="test"
).update(post_title="Updated Title")

# Update all
count = Post.objects.all().update(post_title="Default")
```

### Update Multiple Fields
```python
Post.objects.filter(id=1).update(
    post_title="New Title",
    post_content="New Content"
)
```

### Atomic Increment
```python
from django.db.models import F

Post.objects.filter(id=1).update(views=F('views') + 1)
```

### Bulk Update
```python
posts = list(Post.objects.all()[:10])
for post in posts:
    post.post_title = f"Updated: {post.post_title}"
Post.objects.bulk_update(posts, ['post_title'])
```

### save() vs update()
| Scenario | Method |
|----------|--------|
| Single object with custom logic | `save()` |
| Multiple objects efficiently | `update()` |
| Need signals to fire | `save()` |
| Performance critical bulk update | `update()` |

## Delete Data

### Delete Single Row
```python
from post.models import Post

post = Post.objects.get(id=1)

```

### Delete Multiple Rows
```python
# Delete filtered rows
result = Post.objects.filter(post_title__icontains="test").delete()

result = Post.objects.all().delete()
```


## Aggregation

### Import Functions
```python
from django.db.models import Avg, Max, Min, Sum, Count
```

### Basic Aggregation
```python
# Average
result = Post.objects.aggregate(average_id=Avg('id'))
print(result['average_id'])

# Maximum
result = Post.objects.aggregate(max_id=Max('id'))

# Minimum
result = Post.objects.aggregate(min_id=Min('id'))

# Sum
result = Post.objects.aggregate(total_id=Sum('id'))

# Count
result = Post.objects.aggregate(total=Count('id'))
```

### Multiple Aggregations
```python
result = Post.objects.aggregate(
    min_id=Min('id'),
    max_id=Max('id'),
    avg_id=Avg('id')
)
```

### Filtered Aggregation
```python
result = Post.objects.filter(id__gt=5).aggregate(average_id=Avg('id'))
```

### Conditional Aggregation
```python
from django.db.models import Q

result = Post.objects.aggregate(
    django_posts=Count('id', filter=Q(post_title__icontains='django')),
    other_posts=Count('id', filter=~Q(post_title__icontains='django'))
)
```

## Templates

### Import and Fetch in View
```python
from django.shortcuts import render, get_object_or_404
from .models import Post

def home(request):
    all_posts = Post.objects.all()
    context = {'all_posts': all_posts}
    return render(request, 'index.html', context)

def post_detail(request, post_id):
    post = get_object_or_404(Post, id=post_id)
    context = {'post': post}
    return render(request, 'post.html', context)
```

### Render QuerySet in Template
```html
{% for post in all_posts %}
    <h2>{{ post.post_title }}</h2>
    <p>{{ post.post_content }}</p>
    <p>{{ post.published_date }}</p>
{% empty %}
    <p>No posts found.</p>
{% endfor %}
```

### Render Single Object
```html
<h1>{{ post.post_title }}</h1>
<p>{{ post.post_content }}</p>
<p>Published: {{ post.published_date }}</p>
```

### Template Filters
```html
<!-- Truncate text -->
{{ post.post_content|truncatewords:50 }}

<!-- Date formatting -->
{{ post.published_date|date:"F d, Y" }}

<!-- Default value -->
{{ post.post_title|default:"Untitled" }}

<!-- Capitalize -->
{{ post.post_title|title }}

<!-- Lowercase -->
{{ post.post_title|lower }}

<!-- Line breaks -->
{{ post.post_content|linebreaks }}

<!-- Chain filters -->
{{ post.post_title|default:"Untitled"|title }}
```

### URL Configuration
```python
from django.urls import path
from . import views

urlpatterns = [
    path('', views.home, name='home'),
    path('post/<int:post_id>/', views.post_detail, name='post_detail'),
]
```

## Common Patterns

### Get or Create
```python
post, created = Post.objects.get_or_create(
    post_title="Unique Title",
    defaults={'post_content': 'Default content'}
)
```

### Pagination
```python
from django.core.paginator import Paginator

all_posts = Post.objects.all()
paginator = Paginator(all_posts, 10)
page_number = request.GET.get('page')
page_obj = paginator.get_page(page_number)
```

### Search
```python
query = request.GET.get('q', '')
if query:
    posts = Post.objects.filter(post_title__icontains=query)
else:
    posts = Post.objects.all()
```

### Check if Exists
```python
# More efficient than count()
if Post.objects.filter(post_title__icontains="django").exists():
    print("Django posts exist")
```

### Soft Delete
```python
# Mark as deleted instead of removing
Post.objects.filter(id=1).update(is_deleted=True)
```

## Quick Reference

### QuerySet Methods (Return QuerySets - Chainable)
- `all()` - Get all objects
- `filter()` - Filter objects
- `exclude()` - Exclude objects
- `order_by()` - Order results
- `reverse()` - Reverse order
- `select_related()` - Optimize foreign keys
- `prefetch_related()` - Optimize many-to-many

### QuerySet Methods (Return Objects - Not Chainable)
- `get()` - Get single object (raises exception)
- `first()` - Get first object (returns None if empty)
- `last()` - Get last object (returns None if empty)
- `create()` - Create and save object
- `get_or_create()` - Get or create object
- `update_or_create()` - Update or create object
- `count()` - Count objects (returns int)
- `exists()` - Check if exists (returns bool)

### Model Methods
- `save()` - Save to database
- `delete()` - Delete from database

### Manager Methods
- `Model.objects.all()` - All objects
- `Model.objects.filter()` - Filtered objects
- `Model.objects.get()` - Single object
- `Model.objects.create()` - Create object
- `Model.objects.aggregate()` - Aggregation
- `Model.objects.annotate()` - Per-object calculations

### Field Lookup Reference
- `exact`, `iexact` - Exact match
- `gt`, `gte`, `lt`, `lte` - Comparisons
- `contains`, `icontains` - Contains text
- `startswith`, `istartswith` - Starts with
- `endswith`, `iendswith` - Ends with
- `in` - In list
- `range` - In range
- `isnull` - NULL check
- `regex`, `iregex` - Regular expression
- `year`, `month`, `day` - Date components
- `hour`, `minute`, `second` - Time components

## Common Pitfalls

### Wrong
```python
# Forgetting save()
post = Post(post_title="Title")  # Not saved!

# Using get() on non-unique field
post = Post.objects.get(post_title="Django")  # May raise MultipleObjectsReturned

# Using update() on get() result
post = Post.objects.get(id=1)
post.update(title="New")  # Error! update() only on QuerySets

# Negative slicing on QuerySet
posts = Post.objects.all()[-1]  # Error!

# Not passing context
def home(request):
    posts = Post.objects.all()
    return render(request, 'index.html')  # posts not available
```

### Right
```python
# Always call save()
post = Post(post_title="Title")
post.save()

# Use unique identifiers with get()
post = Post.objects.get(id=1)

# Use filter() for update()
Post.objects.filter(id=1).update(title="New")

# Use last() for last item
posts = Post.objects.all().last()

# Always pass context
def home(request):
    posts = Post.objects.all()
    context = {'posts': posts}
    return render(request, 'index.html', context)
```

## Key Concepts

- **Lazy Evaluation**: QuerySets don't hit DB until accessed
- **QuerySet**: Collection of database objects (like a list)
- **Manager**: Interface for DB queries (default is `objects`)
- **Context**: Dictionary passing data from view to template
- **Migration**: Version control for DB schema
- **Aggregation**: Single result from collection (Avg, Max, Min, Sum, Count)
- **Annotate**: Per-object calculations (different from aggregate)
